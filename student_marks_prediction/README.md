# Student Marks Prediction Using Machine Learning

## Files
- student_marks_prediction.py : complete program
- student_data.csv            : ILLUSTRATIVE sample dataset (30 rows)
- requirements.txt            : libraries needed
- marks_graph.png             : sample output graph
- PROJECT_REPORT.md           : full project report (all 17 sections)

## Quick start
1. Install Python 3.8+ from python.org (tick "Add Python to PATH").
2. Unzip this folder.
3. Open a terminal inside the folder and run:
       pip install -r requirements.txt
       python student_marks_prediction.py
4. Enter study hours when asked. Type q to quit.

## VS Code
File > Open Folder > select this folder > open the .py file >
Terminal > New Terminal > run the two commands above (or click the Run triangle).

## PyCharm
File > Open > select folder > right-click the .py file > Run.
If libraries are missing: open Terminal tab and run pip install -r requirements.txt

## Google Colab
1. Go to colab.research.google.com > New notebook.
2. Click the folder icon (left) > Upload > upload student_data.csv.
3. In a cell paste the whole .py code and press Run (libraries are pre-installed).
4. Type hours in the input box that appears under the cell.
